# Benchmarking

run specifications, model/tool/verification receipts, contamination strata, paired
comparisons, and claim eligibility. Benchmark task bodies, hidden tests, gold patches,
and answer-derived features never enter production retrieval.

The active reference implementation lives in
`src/taedri_codegraph/benchmarking.py` during the transitional vertical slice.
