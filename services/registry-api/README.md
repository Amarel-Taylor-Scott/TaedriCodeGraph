# Registry API

Planned deployable surface for candidate submission, optimistic branch updates,
immutable release tags, forks, reviewed merges, and authorized capsule-pack delivery.

The active intake conformance contract keeps candidate lifecycle events append-only,
requires independent evidence and policy for promotion, blocks producer self-promotion,
and requires verified license evidence before public promotion.

The first deployment may run this contract inside the modular API process. It becomes
an independent service only after a security, scaling, failure-domain, or ownership
gate is measured. It never decides whether a primitive is correct or authorized to run.
