# normalize-unicode-nfkc primitive

`normalize_unicode_nfkc(value)` applies the Unicode Normalization Form KC algorithm from the pinned Python Unicode database and otherwise preserves the string.

Reference semantics:
- https://docs.python.org/3.12/library/unicodedata.html#unicodedata.normalize
- https://www.unicode.org/reports/tr15/
