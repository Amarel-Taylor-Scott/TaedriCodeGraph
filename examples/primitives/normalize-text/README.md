# Normalize text primitive

`normalize_text(value)` removes leading and trailing Unicode whitespace. It has no
third-party dependencies, performs no I/O, and raises `TypeError` for non-string
input. The capsule's examples and tests are executable JSON vectors consumed by the
Taedri local Python acceptance worker.

This directory is the Git collaboration form of the primitive. The Taedri registry
stores the immutable content tree, release evidence, searchable description, and
downloadable pack.
