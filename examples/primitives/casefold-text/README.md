# Case-fold text primitive

`casefold_text(value)` applies Unicode default case folding for caseless comparison.
It has no third-party dependencies, performs no I/O, and raises `TypeError` for
non-string input. The capsule includes executable positive, boundary, and negative
vectors, including a multi-character fold.

This directory is the Git collaboration form of the primitive. The Taedri registry
stores the immutable content tree, interface graph, release evidence, searchable
description, and downloadable pack.
