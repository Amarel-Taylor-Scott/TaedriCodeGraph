# zscore-standardize primitive

`zscore_standardize(values)` validates a finite vector, computes its population mean and variance, and returns z scores; zero-variance vectors produce deterministic zeros.

Reference semantics:
- https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html
