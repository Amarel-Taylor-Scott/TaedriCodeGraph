# canonical-json-object primitive

`canonical_json_object(value)` uses sorted recursive object keys, compact separators, UTF-8 characters, and strict finite-number handling for stable JSON output.

Reference semantics:
- https://docs.python.org/3.12/library/json.html#json.dumps
